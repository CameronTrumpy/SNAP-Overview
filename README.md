# SNAP-Overview

SNAP-Overview is our central repository storing all of the relevant information for SNAP, the low-cost modular electronics workstation.

## SNAP-Overview Content
- [Firmware](./Firmware)
    - Mainboard Module Code
    - Oscilloscope / Logic Analyzer Module Code
    - Power Supply / Waveform Generator Module Code
- [docs](./docs)
    - Code for [snapstation.tech](https://snapstation.tech), our project overview website
    - [In-browser demo of our user interface](https://snapstation.tech/demo.html)
- [Hardware](./Hardware)
    - PDF prints of our schematics for all three modules
    - Altium Project archives
    - Translated KiCad Project archived
    - STEP models of the PCB housings
- [WebUI](./WebUI)
    - The frontend and backend for our web-based user interface
- [SigrokPatch](./SigrokPatch)
    - Our modified version of [Sigrok](http://sigrok.org) with support for SNAP
